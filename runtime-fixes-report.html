Required deployment work

  1. Run npm run runtime:preflight from server against the intended deployment database. This is read-only and reports duplicate IDs plus legacy public document owners. The audit ran it only against isolated local data.
  2. Reconcile any reported duplicate active appointments, daily milk reports or animal identities before running npm run db:migrate. The new migration fails transactionally on duplicates rather than deleting or guessing which business record to keep. Apply migrations before starting the new server.
  3. Configure AWS_S3_PRIVATE_BUCKET as a separate bucket with all S3 public-access blocking enabled and no public bucket policy; grant the backend read/write permissions. New identity-document uploads intentionally fail if separate private storage is missing.

The preflight lists affected veterinarian IDs; live object migration was not authorized or performed.
